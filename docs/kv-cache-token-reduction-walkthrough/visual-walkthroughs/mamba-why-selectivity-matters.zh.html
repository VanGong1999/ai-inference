为什么 Mamba 需要选择性

固定参数的 SSM 如何平等对待每个词——以及为什么这对语言理解是致命缺陷。

↓ 向下滚动探索
第 1 章

固定 SSM 如何读一个句子

我们拿一个简单句子，看看传统的、固定参数的状态空间模型（State Space Model）会怎么处理它。

考虑这句话：“The capital of France is Paris”

在固定 SSM 中，每一步更新隐藏状态（hidden state）的递归是：

ht = Ā × ht-1 + B̄ × xt

这里的关键词是 固定（fixed）。矩阵 Ā 和 B̄ 对每一个 token 都完全相同，无论这个 token 的含义是什么。

B̄ = 0.2

SSM 对待 “The” 和对待 “France” 的重要性是一样的。它对待 “of”——一个毫无意义的虚词——和对待 “Paris”——这个问题的答案——用了同样的权重。它没有办法区分二者。

这就像用完全相同的专注程度去读一本书里的每一个词。你无法跳过 “the cat sat on the”，然后再把注意力集中在 “quantum entanglement（量子纠缠）” 上。每个词都获得同样的脑力。固定 SSM 就是这样。
第 2 章

状态内部发生了什么

我们一步步追踪状态的演化，看看每个 token 的贡献是如何随时间衰减的。

当 Ā = 0.8 且 B̄ = 0.2 时，每个 token 以 0.2 的权重进入状态，然后每一步都以 0.8 的因子衰减。处理完所有五个 token 后，每个 token 的原始贡献在隐藏状态中残留如下：

"The"     : 0.2 × 0.84 = 0.082   (12.8%)
"capital" : 0.2 × 0.83 = 0.102   (16.0%)
"of"      : 0.2 × 0.82 = 0.128   (20.0%) ← 比 "capital" 还多！
"France"  : 0.2 × 0.81 = 0.160   (25.0%)
"is"      : 0.2 × 0.80 = 0.200   (31.2%)

看看这个分布。“of” 以 20% 超过了 “capital” 的 16%，仅仅因为 “of” 出现在后一个位置。而 “is” 以 31.2% 主导了整个状态，仅仅因为它是最新的 token——而不是因为它承载了最多的含义。

在固定 SSM 中，重要性 = 新近程度。 最新的 token 总是主导状态，无论其含义如何。模型根本无法区分内容与噪声。“is” 获得了比 “France” 更多的表示——尽管 “France” 才是预测下一个词所需的关键信息。
第 3 章

Mamba 的修复——内容决定重要性

Mamba 的关键创新是让 SSM 的参数依赖输入（input-dependent）。现在有三个参数随每个 token 变化：Bt、Ct，以及至关重要的 Δt（离散化步长）。

不再是固定的 Ā 和 B̄，Mamba 通过 Δt 从输入计算它们：

Āt = exp(-Δt)     B̄t = 1 - exp(-Δt)

小的 Δ 意味着 “几乎别让这个 token 进来”。大的 Δ 意味着 “这很重要——把它强有力地写进状态”。而 是 token 自己决定了自己的 Δ。

Delta 就像每个 token 的音量旋钮。 小的 Δ = “保留旧状态，几乎别让这个 token 进来。” 大的 Δ = “这很重要！冲刷旧状态，把这个 token 强有力地写进去。”

注意虚词 “of” 只得到 0.05 的微小 Δ，而实词 “France” 得到 2.0 的极大 Δ。模型在训练中学会了 “France” 承载关键信息，而 “of” 只是可以大部分忽略的结构胶水。

第 4 章

Delta——守门人

我们看看 Δ 实际上对信息流做了什么。把它想象成一道控制多少新信息进入隐藏状态的门。

小 Δ（0.05）

无聊的 token：“of”

门几乎关闭——只有涓涓细流

Ā = exp(-0.05) = 0.951
→ 95% 的旧状态被保留

B̄ = 0.049
→ 只有 5% 的输入被写入

大 Δ（2.0）

重要的 token：“France”

门大开——信息洪流涌入

Ā = exp(-2.0) = 0.135
→ 只有 14% 的旧状态幸存！

B̄ = 0.865
→ 87% 的输入被写入！

对比十分鲜明。当门几乎关闭（小 Δ）时，旧状态几乎原样通过，新 token 几乎不被记下。当门大开（大 Δ）时，旧状态被大量冲刷，新 token 占据主导。这正是我们对语言所期望的：实词应该强有力地写入，虚词应该透明无痕。

模型如何选择 Δ？
Δt = softplus(Linear(xt))

token 自己的嵌入（embedding）决定了它的 delta。一个学到的线性投影把输入嵌入映射为一个标量，softplus 保证它为正。模型在训练中学会了哪些 token 值得大的 delta——无需手工调参。

第 6 章

点睛之笔——为什么这改变了一切

让我们把所有东西串起来。这是固定 SSM 与 Mamba 的根本区别。

固定 SSM

  • 每个 token 被平等对待
  • 重要性 = 新近程度
  • 无法做基于内容的过滤
  • 状态被 “is” 主导（31.2%）
  • 虚词污染记忆

Mamba（选择性 SSM）

  • 每个 token 控制自己的门
  • 重要 token 强有力地写入
  • 噪声被自动抑制
  • 状态被 “France” 主导（65.5%）
  • 学到的、内容感知的过滤

当模型看到 “The capital of France is ___” 时，Mamba 的状态被 “France” 以 65.5% 主导。固定 SSM 的状态则被 “is” 以 31.2% 主导。哪一个更可能正确预测出 “Paris”？

选择性不是一种优化。
它是一种必需品。

没有输入依赖参数，序列模型在根本上对内容视而不见。Mamba 的选择性机制给了 SSM 一种选择记住什么、遗忘什么的能力——这与让注意力如此强大的能力相同，但通过优雅的门控而非二次方的计算来实现。
