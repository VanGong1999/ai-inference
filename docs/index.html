02 / 知识地图

你会学到哪些知识点

按主题跳进最合适的入口。每张卡片都是可点击链接。

基础
Roofline 与五指标 TTFT、ITL、吞吐、P99、成本与算术强度
显存
KV Cache 为何 decode 吃带宽，缓存如何成为瓶颈与杠杆
注意力
MHA / MQA / GQA / MLA 跨头压缩：用更少 KV 换吞吐
长序列
滑窗 · SSM · Mamba 跨 token 压缩与线性时间序列模型
内核
FlashAttention 1/2/3 Tiling、online softmax、与硬件对齐的内核
Serving
PagedAttention · vLLM 分页 KV、前缀缓存、连续批处理的一步解剖
精度
量化 GPTQ / AWQ 权重量化如何抬升 decode 吞吐
加速
投机解码 Draft / Verify、树验证、MTP、EAGLE
扩展
张量 / 流水线 / 专家并行 多卡与 MoE 上的并行策略
架构
分离式 Prefill / Decode 拆分阶段、缓存感知路由与扩缩容
多模态
VLM · ASR · TTS · 视频 不止文本：多模态推理的工程差异
生产
容器化 · 多云 · 自动扩缩 把引擎放进可运维的生产环境
