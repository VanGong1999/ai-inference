问题

每一层读取一个局部块。

可达范围（Reach）
三次局部跳跃就能覆盖整个 12-token 句子。

核心直觉

感受野（receptive field）的意思是「哪些更早的 token 能影响我？」

在单层中

如果 token 12 只能关注 token 9、10、11 和 12，那么经过一层之后，它直接知道的就只有这个短语：

the9 dusty10 mat11 yesterday12
第 1 层在 token 12 处看到 9..12

堆叠之后

第 2 层的 token 12 读取它附近第 1 层的 token。但那些第 1 层的 token 已经包含了它们自己的局部历史。 因此可达的输入 token 向左扩展。

red6 key7 under8 the9 dusty10 mat11 yesterday12
第 2 层在 token 12 处大约看到 6..12
用大白话来说：一层不只是读取原始词。它读取的是上一层做出的摘要。那些摘要已经携带了附近的上下文，因此上下文像接力一样传播。

接力：第 3 层的 token 12 读取附近第 2 层的状态。那些第 2 层的状态读取附近第 1 层的状态。 那些第 1 层的状态读取附近的输入 token。所以模型没有使用全局注意力，但信息仍然在句子中传递。
为什么重要

局部窗口节省了注意力计算，但召回能力受深度限制。

全注意力

每个 token 都能在单层内直接关注到每一个之前的 token。召回能力强，但对长上下文代价高昂。

每层计算量 ≈ N × N

滑动窗口注意力

每个 token 只关注一个固定的局部窗口。便宜得多，但远处的 token 需要经过多层才能影响到当前 token。

每层计算量 ≈ N × W

精确公式与课堂捷径

如果 W 表示包括当前 token 在内的因果 token 总数，那么 L 层之后的精确感受野是：

RF = 1 + L × (W - 1)

当 W=4、L=3 时，就是 1 + 3×3 = 10 个 token。许多图会使用粗略的捷径 W×L，或者把 W 定义为「每层新增的左侧位置」， 这样得到的直觉很干净：大约是 4×3 = 12 个位置。

这就是为什么有些架构会把局部/滑动窗口层与偶尔的全注意力或全局 token 层混合使用： 局部注意力便宜，而偶尔的全局混合能恢复长距离的召回。
