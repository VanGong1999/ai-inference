## 附录 A：关键公式速查（Key Formulas Reference）

| 概念 | 公式 |
|---|---|
| 注意力（Attention） | `Attn(Q, K, V) = softmax(QKᵀ / √d_k) · V` |
| KV Cache 大小 | `2 × L × n × H × d_h × bytes` |
| Roofline | `性能 = min(峰值 FLOP/s, 算术强度 I × 内存带宽 B_mem)` |
| 投机解码加速 | `E[接受数] = (1 − α^(K+1)) / (1 − α)` |
| 流水线气泡 | `(p − 1) / (m + p − 1)` |
| 量化步长 | `s = (x_max − x_min) / (2^b − 1)` |
| MFU | `实际 FLOP/s / 峰值 FLOP/s` |
| 每 Token 成本 | `GPU 每小时成本 / 每小时 token 数` |

## 附录 B：带注论文阅读清单（Annotated Paper Reading List）

1. **Attention Is All You Need**（Vaswani et al., 2017）—— Transformer 奠基论文，先读这篇。
2. **FlashAttention**（Dao et al., 2022）与 **FlashAttention-2**（Dao, 2023）—— 理解 IO 感知注意力计算的必读。
3. **Efficient Memory Management for LLM Serving**（vLLM/PagedAttention）（Kwon et al., 2023）—— 重新定义 LLM 服务的论文。
4. **GPTQ**（Frantar et al., 2022）与 **AWQ**（Lin et al., 2023）—— 基础量化方法。
5. **Fast Inference from Transformers via Speculative Decoding**（Leviathan et al., 2023）—— 投机解码的数学严谨处理。
6. **Medusa**（Cai et al., 2024）—— 无需草稿模型的多头投机解码。
7. **EAGLE-2**（Li et al., 2024）—— 动态树的 SOTA 投机解码。
8. **DeepSeek-V2**（DeepSeek, 2024）—— MLA 与 MoE 的高效推理创新。
9. **Mamba**（Gu & Dao, 2023）—— 作为注意力高效替代的状态空间模型。
10. **Sarathi-Serve**（Agrawal et al., 2024）—— 面向延迟公平的分块预填充。
11. **Scaling LLM Test-Time Compute Optimally**（Snell et al., 2024）—— 推理时计算扩展的正式处理。
12. **DeepSeek-R1**（DeepSeek, 2025）—— 用 GRPO 的 RL 训练推理。
13. **Multi-Token Prediction**（Gloeckle et al., 2024）—— 预测多 token 的训练与推理收益。
14. **Mixture of Depths**（Raposo et al., 2024）—— 自适应逐层计算。
15. **StreamingLLM**（Xiao et al., 2023）—— 注意力汇与无限长度推理。

## 附录 C：术语表（Glossary）

| 术语 | 定义 |
|---|---|
| **AWQ** | Activation-aware Weight Quantization（激活感知权重量化）。量化前按激活幅值缩放通道的 PTQ 方法。 |
| **BF16** | Brain Float 16。与 FP32 指数范围相同的 16 位格式，广泛用于 LLM 训练与推理。 |
| **FLOP** | Floating Point Operation（浮点运算）。 |
| **GQA** | Grouped Query Attention（分组查询注意力）。多组 query 头共享一对 KV 的注意力变体。 |
| **GPTQ** | 逐层二阶 PTQ 方法，用 Hessian 信息做权重量化。 |
| **HBM** | High Bandwidth Memory（高带宽内存）。现代 GPU 用的 DRAM 类型（HBM2e、HBM3）。 |
| **KV Cache** | Key-Value 缓存。存储此前生成 token 的注意力 key 和 value。 |
| **MFU** | Model FLOP Utilization（模型 FLOP 利用率）。峰值 FLOP/s 中被有效使用的比例。 |
| **MLA** | Multi-head Latent Attention（多头潜在注意力）。用压缩潜在 KV 表示的注意力变体。 |
| **MoE** | Mixture of Experts（混合专家）。有多个专家 FFN 和 token 路由的模型架构。 |
| **MQA** | Multi-Query Attention（多查询注意力）。所有 query 头共享一对 KV。 |
| **NVLink** | NVIDIA 的高带宽 GPU 间互连（H100 上 900 GB/s）。 |
| **PagedAttention** | 用虚拟内存分页管理 KV Cache 的方法。 |
| **PRM** | Process Reward Model（过程奖励模型）。给中间推理步骤打分的奖励模型。 |
| **PTQ** | Post-Training Quantization（训练后量化）。训练后应用的量化。 |
| **QAT** | Quantization-Aware Training（量化感知训练）。训练中融入量化。 |
| **RoPE** | Rotary Positional Embeddings（旋转位置嵌入）。通过复旋转编码位置。 |
| **SSM** | State Space Model（状态空间模型）。用学到的循环状态的序列模型（Mamba、S4）。 |
| **TPOT** | Time Per Output Token（每输出 token 时间）。相邻输出 token 之间的时长。 |
| **TTFT** | Time To First Token（首 token 时间）。从请求到首个输出 token 的时长。 |
| **Tensor Core** | 加速矩阵乘法的 GPU 专用计算单元。 |
| **vLLM** | Virtual LLM。用 PagedAttention 和连续批处理的高吞吐服务系统。 |
