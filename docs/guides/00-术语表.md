# 中英对照术语表

> 本术语表按主题分组，统一采用「中文（English）」格式。阅读英文书籍或笔记遇到不熟悉的词时，可回到这里查询。

## 1. 推理基础流程

| 术语 | 中文 | 说明 |
|---|---|---|
| Inference | 推理 | 使用训练好的模型生成输出的过程，与训练（training）相对 |
| Prefill | 预填充 | 一次性处理所有输入 prompt token，生成第一个输出 token 之前的阶段，计算密集（compute-bound） |
| Decode | 解码 | 逐个生成后续 token 的阶段，每次迭代为每个活跃请求生成一个 token，内存带宽敏感（memory-bound） |
| Autoregressive | 自回归 | 逐个 token 生成，每个 token 依赖之前所有 token |
| Token | 词元 / token | 文本被切分后的最小处理单元 |

## 2. 关键指标

| 术语 | 中文 | 说明 |
|---|---|---|
| TTFT（Time to First Token） | 首 token 延迟 | 从请求发出到第一个 token 返回的时间，主要受 prefill 影响 |
| ITL（Inter-Token Latency） | token 间延迟 | 相邻两个 token 之间的时间间隔，又称 TPOT |
| TPOT（Time Per Output Token） | 每输出 token 时间 | 同 ITL，decode 阶段的平均单 token 时间 |
| Throughput | 吞吐量 | 单位时间处理的 token 数（tokens/sec）或请求数（requests/sec） |
| P50 / P90 / P99 | 百分位延迟 | 50%/90%/99% 的请求延迟低于该值；P99 常用来衡量尾延迟（tail latency） |
| Cost per token | 每 token 成本 | 单位 token 的推理成本 |

## 3. Roofline 与硬件

| 术语 | 中文 | 说明 |
|---|---|---|
| Roofline model | Roofline 模型 | 可视化性能上限的模型，横轴算术强度，纵轴性能，区分 compute-bound 与 memory-bound |
| Arithmetic intensity | 算术强度 | 每字节内存访问对应的浮点运算数（FLOPs/byte） |
| Compute-bound | 算力受限 | 受限于 GPU 计算能力（FLOPS） |
| Memory-bound | 内存带宽受限 | 受限于 HBM 内存带宽，是 decode 阶段的典型瓶颈 |
| HBM（High Bandwidth Memory） | 高带宽内存 | GPU 上的高速显存 |
| SRAM | 静态随机存取内存 | GPU 片上高速缓存，FlashAttention 用它做 tiling |
| FLOPs | 浮点运算次数 | 计算量的度量 |

## 4. KV Cache 与注意力

| 术语 | 中文 | 说明 |
|---|---|---|
| KV Cache | KV 缓存 | 缓存每层注意力中 K、V 矩阵，避免 decode 时重复计算历史 token |
| MHA（Multi-Head Attention） | 多头注意力 | 标准注意力，每个头有独立 K、V |
| MQA（Multi-Query Attention） | 多查询注意力 | 所有头共享一组 K、V，大幅减少 KV 缓存 |
| GQA（Grouped-Query Attention） | 分组查询注意力 | 头分成若干组，组内共享 K、V，是 MHA 与 MQA 的折中 |
| MLA（Multi-head Latent Attention） | 多头潜在注意力 | DeepSeek 提出的低秩 KV 联合压缩，降低 KV 缓存 |
| Sliding window attention | 滑动窗口注意力 | 每个 token 只关注附近固定窗口内的 token |
| Linear attention | 线性注意力 | 用核技巧将注意力复杂度从 O(n²) 降到 O(n) |
| SSM（State Space Model） | 状态空间模型 | 用递归状态描述序列，可表达为卷积，Mamba 的基础 |
| Mamba | Mamba | 一种选择性状态空间模型（selective SSM），输入相关的状态转移 |
| Receptive field | 感受野 | 一个 token 能「看到」的上下文范围 |

## 5. 注意力优化与内存

| 术语 | 中文 | 说明 |
|---|---|---|
| FlashAttention | FlashAttention | 通过 tiling 与 online softmax 减少注意力计算的 HBM 读写，分 1/2/3 三代 |
| Tiling | 分块 | 把大矩阵切块，逐块在 SRAM 中计算 |
| Online softmax | 在线 softmax | 流式计算 softmax 的归一化因子，避免重复读完整矩阵 |
| PagedAttention | 分页注意力 | vLLM 提出，把 KV 缓存按块（block）管理，减少显存碎片 |
| Prefix caching | 前缀缓存 | 复用共享前缀的 KV 块，避免重复 prefill |
| RadixAttention | 基数树注意力 | SGLang 的前缀缓存实现，用基数树（radix tree）管理共享前缀 |
| Chunked prefill | 分块预填充 | 把长 prompt 的 prefill 拆块，与 decode 交替，避免阻塞 decode |

## 6. 量化与压缩

| 术语 | 中文 | 说明 |
|---|---|---|
| Quantization | 量化 | 用低精度（如 INT8/INT4）表示权重/激活，减少内存与带宽 |
| Symmetric / Asymmetric quantization | 对称 / 非对称量化 | 零点是否为零的两种量化方式 |
| GPTQ | GPTQ | 一种训练后量化（post-training quantization）方法 |
| AWQ（Activation-aware Weight Quantization） | 激活感知权重量化 | 按激活重要性保护关键权重通道 |
| QAT（Quantization-Aware Training） | 量化感知训练 | 训练时模拟量化，保留精度 |
| Weight-only / W8A8 | 仅权重量化 / 权重激活都量化 | 只量化权重，或权重与激活都量化的两种策略 |

## 7. 批处理与加速

| 术语 | 中文 | 说明 |
|---|---|---|
| Continuous batching | 连续批处理 | 请求完成即插入新请求，不等待整批完成，提高 GPU 利用率 |
| Static batching | 静态批处理 | 整批一起开始、一起结束，简单但利用率低 |
| Speculative decoding | 投机解码 | 用小模型/多头草稿快速生成候选 token，再由大模型并行验证 |
| Acceptance rate | 接受率 | 投机解码中草稿 token 被大模型接受的比例 |

## 8. 并行与分布式

| 术语 | 中文 | 说明 |
|---|---|---|
| Tensor parallelism | 张量并行 | 把单层权重切分到多个 GPU，通常用在高带宽 NVLink 域内 |
| Pipeline parallelism | 流水线并行 | 把不同层放到不同 GPU，跨节点通信代价高 |
| Expert parallelism | 专家并行 | MoE 模型中把不同专家放到不同 GPU |
| Data parallelism | 数据并行 | 复制模型，把请求分发到不同副本 |
| Sequence parallelism | 序列并行 | 把序列维度切分到多 GPU |
| Context parallelism | 上下文并行 | 长上下文的序列级并行变体 |
| NVLink / InfiniBand | NVLink / InfiniBand | 机内 / 机间高速互联 |

## 9. 生产系统

| 术语 | 中文 | 说明 |
|---|---|---|
| Disaggregated serving | 分离式服务 | 把 prefill 与 decode 放到不同资源池，各自独立扩缩 |
| KV transfer tax | KV 传输税 | 分离式服务中 prefill 池向 decode 池传输 KV 的开销 |
| Autoscaling | 自动扩缩容 | 根据负载自动增减副本 |
| Warm pool | 预热池 | 常驻的已加载模型副本，降低冷启动延迟 |
| Cold start | 冷启动 | 从零加载模型、分配显存、初始化运行时的过程 |
| Canary deployment | 金丝雀部署 | 小比例流量先切到新版本，验证后逐步放量 |
| Cache-aware routing | 缓存感知路由 | 把请求路由到已有其前缀 KV 缓存的副本 |
| Guardrails | 护栏 | 输入/输出侧的安全与合规检查 |
| Structured output | 结构化输出 | 让模型输出符合 schema 的 JSON 等机器可读格式 |
| Guided decoding | 引导解码 | 用语法/schema 屏蔽非法 token |
| Logit biasing | logit 偏置 | 采样前调整 token 概率，软性引导输出 |
| LLM judge | LLM 评判器 | 用模型评估另一个模型输出的质量 |

## 10. 微调与其它

| 术语 | 中文 | 说明 |
|---|---|---|
| LoRA（Low-Rank Adaptation） | 低秩适配 | 用低秩矩阵微调，参数量小、可插拔 |
| QLoRA | 量化低秩适配 | 在量化基座模型上做 LoRA |
| Distillation | 蒸馏 | 用大模型（教师）训练小模型（学生） |
| SFT（Supervised Fine-Tuning） | 监督微调 | 用标注数据微调模型 |
