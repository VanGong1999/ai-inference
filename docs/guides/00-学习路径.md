# 完整学习路线与章节对照表

本文件给出从「零基础」到「能设计生产级推理系统」的完整学习路线，并提供 **书籍章节 ↔ 讲座 ↔ 中文导读** 的三栏对照表。

## 一、学科全景

AI 推理工程（Inference Engineering）研究的是：**一个训练好的模型，如何被高效、低成本、低延迟地服务出去**。它关心的不是「模型为什么聪明」，而是：

- 一个 GPU 上一次前向传播里，算术强度（arithmetic intensity）决定了你是否浪费了 99% 的硬件。
- KV Cache 如何让解码（decode）从「重算一切」变成「复用一切」。
- PagedAttention、连续批处理（continuous batching）、投机解码（speculative decoding）如何把 GPU 利用率拉到极限。
- 分离式服务（disaggregated serving）、路由、自动扩缩容如何让系统在真实流量下存活。

核心主线是 **Roofline 模型**：区分「算力受限」（compute-bound）与「内存带宽受限」（memory-bound）两种工作负载，从而知道该优化什么。

## 二、推荐学习路线

### 阶段 1：建立心智模型（约 ch0–ch4）

1. 读 [`00-术语表.md`](00-术语表.md)，建立基本词汇。
2. 读书籍 [ch0](../book.zh.html#ch00-inference-engineers-world)–[ch4](../book.zh.html#ch04-pretraining-in-one-page)：
   - 理解推理工程师做什么（ch0）
   - 三层架构：运行时 / 基础设施 / 工具（ch1）
   - 五个关键指标：TTFT、ITL/TPOT、吞吐、P99、成本（ch2）
   - Roofline 模型与算术强度（ch3）
   - 预训练一页回顾（ch4）
3. 对照导读 [`lectures/01-推理工程导论.md`](lectures/01-推理工程导论.md)。

### 阶段 2：KV Cache 与注意力（ch5–ch10）

1. 读书籍 [ch5](../book.zh.html#ch05-naive-inference-and-redundancy)–[ch10](../book.zh.html#ch10-flash-attention)。
2. 重点理解：
   - 为什么朴素推理会重复计算（ch5）
   - GPU 硬件（ch6）
   - KV Cache 的善与恶（ch7）
   - 跨头压缩 MHA/MQA/GQA/MLA（ch8）
   - 跨 token 压缩：滑窗/线性注意力/SSM/Mamba（ch9）
   - FlashAttention 的 tiling 与 online softmax（ch10）
3. 对照导读 `02`、`03`、`04`、`05`。

### 阶段 3：服务优化（ch11–ch16）

1. 读书籍 [ch11](../book.zh.html#ch11-paged-attention)–[ch16](../book.zh.html#ch16-parallelism)。
2. 重点理解 PagedAttention、前缀缓存、量化、连续批处理、投机解码、并行。
3. 对照导读 `06`、`07`、`08`。

### 阶段 4：生产系统（ch17–ch20 + 笔记）

1. 读书籍 [ch17](../book.zh.html#ch17-disaggregated-prefill-decode)–[ch20](../book.zh.html#ch20-engine-landscape)。
2. 阅读[生产系统笔记](../lecture-notes/l13-production-inference-systems/README.md)（含中文翻译）。

### 阶段 5：前沿与实战（ch21–ch26 + 讲座 10/11）

1. 读书籍 [ch21](../book.zh.html#ch21-inference-quest)–[ch26](../book.zh.html#ch26-capstone3-openclaw-rl)。
2. 动手做硬件实验（讲座 10）与 Capstone（讲座 11）。
