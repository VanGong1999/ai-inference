# 第 10 讲 · 硬件实验（Jetson / Raspberry Pi / Modal）

> 硬件实验：Jetson Orin Nano、树莓派，以及 Modal 上的 vLLM。

## 本讲讲了什么

这一讲把前面所有的「纸上优化」落地到**真实硬件**上，回答一个关键问题：**同样的推理任务，在不同硬件上会遇到完全不同的瓶颈。** 通过三组实验，建立对「硬件—软件协同」的直觉。

三组实验：

1. **Jetson Orin Nano**（NVIDIA 边缘设备）：在边缘 GPU 上跑推理，理解**功耗受限、内存带宽有限**的设备上，量化、批处理、KV Cache 的取舍与云端有何不同。配套 `Vizuara_AI_Jetson_Orin_Nano_Setup_Guide.pdf`。
2. **Raspberry Pi**（树莓派，CPU 边缘设备）：在无 GPU 的纯 CPU 设备上跑小模型，直观感受「没有 GPU 加速时，内存带宽与算力到底有多紧张」，理解为什么量化（如 GGUF/llama.cpp）对边缘部署至关重要。配套 `Raspberry_Pi_Inference_Lab_Module.pdf`。
3. **Modal + vLLM（云端 GPU）**：在 Modal 的无服务器 GPU 容器上用 vLLM 部署多模态模型，做并发压测。这是 Capstone 的**前置实验**（实验 4），也是「生产级推理系统」的入门。

这一讲的核心收获是**「按硬件特性做推理决策」**：

- 边缘 CPU → 极致的量化 + 小模型；
- 边缘 GPU → 功耗与内存带宽约束下的 batch/精度权衡；
- 云端 H100 → 吞吐优先，但要注意并发、批处理、前缀缓存、分块预填充等。
