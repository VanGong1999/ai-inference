# 第 07 讲 · 量化（Quantization）

> All About Quantization

## 本讲讲了什么

量化（Quantization）是推理优化中「用精度换内存与带宽」的核心技术：把高精度（FP16/BF16）的权重和激活用低精度（INT8/INT4 甚至更低）表示，从而**减小模型体积、降低显存占用、缓解 decode 阶段的内存带宽瓶颈**。

本讲从浮点表示讲起，逐步展开：

- **浮点与整数表示**：FP32 的位布局（符号/指数/尾数）、各种低精度格式（FP16、BF16、INT8、INT4）的「格式动物园（format zoo）」。
- **对称 vs 非对称量化**：对称量化（symmetric）零点固定为 0，非对称量化（asymmetric）引入零点（zero-point）以更好拟合偏斜的分布。
- **量化粒度**：逐张量（per-tensor）、逐通道（per-channel）、逐块/逐 tile（tile/block scaling）——粒度越细，精度越好，但开销越大。
- **关键难点：激活离群值（channel outliers）**：激活里少数通道的数值特别大（Dettmers 等发现），会严重破坏 INT8 量化的精度。AWQ（激活感知权重量化）通过保护这些关键通道来缓解。
- **两种主流训练后量化（PTQ）方法**：
  - **GPTQ**：逐层迭代地量化权重，并在量化时补偿误差（error flow）。
  - **AWQ**：根据激活的幅度选择性地缩放权重，保护重要通道。
  - **GGUF/两级量化**：llama.cpp 用的格式，块层级 + 两级量化（two-level quantization），用于在 CPU/边缘设备上跑模型。
- **QAT（量化感知训练）**：训练时模拟量化（fake quantization），让模型适应量化误差，通常精度损失更小，但需要重训。
- **为什么窄极小值更稳（wide vs narrow minima）**：量化相当于给权重加噪声，落在「宽而平」的极小值附近的模型更鲁棒。

一句话总结：**量化的本质是在「内存/带宽收益」与「质量损失」之间找平衡，而且这个平衡必须用评测（eval）来验证，而不是想当然。**
