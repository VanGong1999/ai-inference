# 第 09 讲 · Bonus：推理与 YCombinator

> Bonus Lecture: Inference and YCombinator

## 本讲讲了什么

这是一讲**Bonus**，把视角从「技术细节」拉到「商业与创业」层面：**推理工程如何成为一个可被投资、可被创业的方向**，以及为什么 YCombinator（YC）这样的顶级孵化器会关注推理基础设施。

核心线索是「推理的想法日志（Inference Ideas Journal）」：系统性地梳理推理工程这一波浪潮里，还有哪些「值得创业」的空白点。它把前面讲过的技术（KV Cache、量化、投机解码、分离式服务、多区域路由等）重新组织成「产品 / 公司机会」的视角。

本讲通常会讨论：

- 推理成本下降带来的**新商业模式**：当「服务一个 LLM」越来越便宜，哪些上层应用会变得可行。
- **推理基础设施的机会**：从专用推理芯片、边缘推理、到推理侧的缓存 / 路由 / 成本优化平台。
- **端侧（on-device）与云端（cloud）的边界**：哪些任务该在本地跑、哪些该在云端跑。
- **创业的取舍**：作为创业者，如何在「通用平台」与「垂直场景」之间选择，如何判断一个推理优化是否值得做成产品。

它不引入新的硬核数学，而是帮你把「技术能力」转译成「价值判断」，适合想走创业 / 产品路线的人。
