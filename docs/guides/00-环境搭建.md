# 环境搭建指南

本文件说明如何运行本仓库中的 Jupyter notebook、benchmark、Capstone 项目，以及如何本地预览站点、配置 GitHub Pages。

## 1. 运行 Jupyter notebook

本仓库的 notebook 位于 `lectures/` 目录，例如：

- `lectures/02-good-and-evil-of-kv-cache/` —— KV Cache 演示与 TurboQuant
- `lectures/02-good-and-evil-of-kv-cache/Assignment KV Cache Pods/` —— 9 个分节的 KV Cache 作业
- `lectures/03-attention-variants-part-1/` —— MHA/MQA/GQA/MLA 基准
- `lectures/05-flash-attention/` —— FlashAttention 基准

### 安装 Jupyter

```bash
pip install jupyter jupyterlab
```

### 启动

在仓库根目录执行：

```bash
jupyter notebook
# 或
jupyter lab
```

然后导航到对应 `.ipynb` 文件打开即可。

> 部分 notebook 依赖 PyTorch、Transformers、flash-attn 等。建议用虚拟环境隔离：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install torch transformers
```

## 2. 运行 KV Cache benchmark（讲座 03）

`lectures/03-attention-variants-part-1/` 中有一个 MHA/GQA/MQA/MLA 的 KV Cache 基准：

- `Clean_KV_Cache_Inference_Benchmark_MHA_GQA_MQA_MLA.ipynb` —— 主 notebook
- `run_tinystories_kv_benchmark.py` —— 辅助脚本，在 TinyStories 数据集上跑消融实验

作业要求（详见该目录 `Links.txt`）：

1. 移除 RoPE 部分，构造一个 boilerplate notebook，在 TinyStories 上对以下配置跑消融：
   - MQA
   - GQA（把 group size 作为超参数）
   - MLA（把 latent dim 作为超参数）
   - MHA
2. 基准指标：
   - 计算指标：KV Cache 大小、token 间延迟（ITL）、P99、P50
   - 质量指标：生成文本的语法流畅度、困惑度（perplexity）、验证损失（validation loss）

论文链接：<https://arxiv.org/pdf/2506.09342>

## 3. Capstone 环境（Modal + vLLM）

Capstone 项目位于 `lectures/11-capstone-project/` 与 `lectures/10-hardware-labs/infertutor-arena-capstone-main/`。目标是在 Modal 上用 vLLM 部署多模态 LLM 服务（`Qwen/Qwen3-VL-4B-Instruct`），做并发压测并优化推理指标。

### 依赖

`starter_code/requirements.txt` 内容：

```text
modal>=1.4.0
httpx>=0.28.0
rich>=13.9.0
fpdf2>=2.8.0
```

### 快速开始

```bash
cd lectures/10-hardware-labs/infertutor-arena-capstone-main/starter_code
pip install -r requirements.txt

# 认证 Modal
modal token new

# 创建 Hugging Face secret（用于下载模型）
modal secret create huggingface HF_TOKEN=<YOUR_HF_TOKEN>
```

### 冒烟测试

```bash
python run_infertutor_experiment.py \
  --label smoke --gpu-type H100 --replicas 1 \
  --mode text --users 5 --duration 30 --ramp-up 5 --max-tokens 64
```

### 主要多模态基线

```bash
python run_infertutor_experiment.py \
  --label mixed-r2 --gpu-type H100 --replicas 2 \
  --max-seqs 32 --max-batch-tokens 4096 \
  --mode mixed --users 100 --duration 90 --ramp-up 25 --max-tokens 96
```

### 评分与清理

```bash
python score_infertutor.py results_infertutor   # 汇总结果、算 leaderboard 分数

modal app list                                  # 实验结束后停止应用，避免计费
modal app stop <APP_ID_OR_NAME>
```

> 完整作业说明见 `lectures/10-hardware-labs/infertutor-arena-capstone-main/InferTutor_Arena_Capstone.pdf` 与 `Modal_vLLM_Runbook.pdf`。

## 4. 本地预览站点

本仓库的站点根目录是 `docs/`，可直接用 Python 起一个静态服务器预览：

```bash
cd docs
python3 -m http.server 8000
```

浏览器打开 <http://localhost:8000/>：

- 首页：中文门户（`index.html`）
- 书籍：<http://localhost:8000/book.html>
- Walkthrough 索引：<http://localhost:8000/visual-walkthroughs.html>

> 站点内请通过 `md.html?src=...` 阅读导读，例如：<http://localhost:8000/md.html?src=guides/lectures/06-vLLM-Step-的解剖.md>。这样会渲染标题、加粗、表格等排版。源 `.md` 仍可在 GitHub 仓库页面直接阅读。

## 5. GitHub Pages 配置

1. 将仓库 push 到 GitHub（`origin` 已指向 `https://github.com/VanGong1999/ai-inference.git`）：

   ```bash
   git add -A
   git commit -m "Reorganize into Chinese-guided inference engineering repo"
   git push -u origin main
   ```

2. 在 GitHub 仓库页面：**Settings → Pages → Source**，选择 **Deploy from a branch**，Branch 选 `main`，目录选 `/docs`，保存。

3. 等待构建完成，访问：

   ```text
   https://vanguong1999.github.io/ai-inference/
   ```

> 详细部署说明见根目录 [`DEPLOY.md`](../../DEPLOY.md)。

## 6. 常见问题

| 问题 | 解决 |
|---|---|
| notebook 打开很慢或内核崩溃 | 升级 `jupyter`，或在虚拟环境中运行 |
| `flash-attn` 安装失败 | 不同平台需要预编译 wheel；KV Cache 基准 notebook 多数情况下不需要真实 flash-attn，可用标准 attention 替代 |
| Modal 部署报认证错误 | 运行 `modal token new` 重新认证，确认 `HF_TOKEN` secret 已创建 |
| 本地预览 `.md` 显示为纯文本 | 正常现象，Markdown 导读在 GitHub 上阅读体验最佳 |
