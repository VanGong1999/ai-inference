为什么卷积其实没那么贵：一段音乐之旅。

麦克风把声音记录为随时间变化的气压：低压、高压、再低压，每秒采样数千次。 为了添加混响（reverb），我们要问一个实际问题：每一个压力采样（sample）应该如何回响到未来？

FFT把它们结合起来的快速方法
1. 声音问题

混响，是歌曲发声之后房间对它的回应。

想象在一个完全没有混响的录音棚里，有一个干净的小提琴音符。现在把这同一个音符 搬到音乐厅里。直达音符先到达你的耳朵；接着，更轻的副本会从墙壁、天花板、座椅和 房间后部反射回来。

这种回响模式被称为脉冲响应（impulse response）：如果房间听到一声极短的 咔哒声，它之后会如何鸣响？混响，就是把歌曲与这个房间响应混合在一起。

本页面在你的浏览器中合成音符与混响，不需要任何音频文件：干声音符是一个小小的 泛音音色，房间则是一个逐渐衰减的回响模式。

2. 慢速的混响计算

直接卷积要求每一个输出采样都穿越时间往回看。

如果房间持续回响 N 个采样，那么每个输出采样都必须问：当前的音符、前一个音符、 再前一个音符……各有多少应该被加到这里？

y[t] = Σ song[t - j] · room[j]

这就是卷积（convolution）。慢速版本是 N 个输出时刻乘以 N 种可能的回声延迟， 也就是平方形状的 N²。

每一行是一个输出时刻。

每个彩色格子都是一个过去的采样被混入一个新的混响采样。

3. 快速路径

FFT 说：按频率把歌曲和房间结合，然后再回到时间域。

歌曲是随时间变化的压力，房间响应也是随时间变化的一小段信号。FFT 把两者都转换为 频率系数（frequency coefficients）。然后混响就变简单了：把对应的频率仓相乘， 再用逆 FFT 变回压力采样。

小小修正：这不是一个大的点积，而是逐点相乘：歌曲频率 0 乘以房间频率 0， 歌曲频率 1 乘以房间频率 1，以此类推。

4. 频率旋钮的迷你版本

在整首歌之前，先用八个数字。

现在我们把声音的概念缩小成一个小序列： [3, 5, 3, 1, 3, 5, 3, 1]。这个玩具波形能让我们看清楚 重复的工作究竟藏在哪里。

核心思想

直接 DFT 会从零开始计算每个频率。FFT 则发现，像 X2 和 X6 这样的成对系数，共享相同的偶数位计算， 以及同一份奇数位计算的翻转版本。

每对的共享计算 × log₂(N) 层

这种反复的共享，就是计算量变成 N log N 的直观原因。

时间序列是 [3, 5, 3, 1, 3, 5, 3, 1]。 频率的问题是：从 X0 到 X7 这八个系数分别是什么？ 一旦我们得到它们，逆 DFT 就会在每个时间步把八个基波加回一起。

xn = (1/8) Σk=07 Xk W8-kn

随着 k 增大，基波会越来越快。在这个干净的例子里，只有 X0、X2 和 X6 是活跃的。 其他波形的旋钮都是零，所以它们的波被显示为静默。

在每个 n 处把活跃的分量加起来。

平坦层在每一处都贡献 3。X2/X6 这对贡献了实正弦摆动 [0, 2, 0, -2, 0, 2, 0, -2]。两者之和重建了原始序列。

5. 求系数的慢速方法

直接 DFT 会让每个系数与每个时间值相乘。

要直接求出 X0 到 X7，每个频率行都要扫描全部八个时间值。 每个彩色格子都是 DFT 求和中的一次乘加交互。

Xk = Σn=07 xn W8kn

八个系数行乘以八个输入列，得到 64 次交互。一般地：N 行乘以 N 列得到 N²。

6. 为什么可以复用

对于 X2 和 X6，角度会重复，只是有一个干净的翻转。

对于每个系数，每个时间值都会得到一个方向。数值决定箭头的长度；系数决定角度的模式。

对于 X2 角度依次是 0°、90°、180°、270°，然后同样的四个方向重复。
对于 X6 偶数位保持与 X2 相同的角度。奇数位垂直翻转：90° 变成 270°，270° 变成 90°。
关键的复用 X2 和 X6 不需要两次完全独立的扫描。拆成偶数组和奇数组，复用这些汇总， 然后翻转奇数汇总以得到配对的系数。

现在通过把八个彩色向量相加来求 X2 和 X6。

每个时间值都变成一个向量。数值决定箭头的长度；角度来自我们正在计算的系数。 我们把箭头当作向量来相加，而不是当作单纯的标量大小。

可视化复用：计算一个偶数节点和一个奇数节点，然后得到两个输出。

对于 X2 和 X6，偶数卡片完全相同。奇数卡片数值相同，但垂直翻转。 因此我们可以把八个箭头概括为两个可复用的节点。

7. 为什么这会变成 N log N

复用逐层发生：8 → 4 → 2 → 1。

N

每层的工作量

在某一层，每个值都属于一个小小的偶/奇复用组。

log N

层的数量

把问题不断减半得到 8 → 4 → 2 → 1，也就是 N = 8 时有 3 层。

每层 N 个值 × log₂(N) 层 = N log N
