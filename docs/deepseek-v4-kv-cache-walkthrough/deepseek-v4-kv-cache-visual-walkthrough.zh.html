为什么这很重要

相比传统 KV 缓存的收益

每个旧 token 更少内存

传统缓存同时存储 K 和 V。DeepSeek V4 先存一个共享状态，所以每个旧 token 起步就更便宜。

更旧的历史变得更小

C4A 和 C128A 把许多共享状态变成更少的摘要块，所以长上下文不会增长得那么快。

近期细节保持精确

最新的 token 保持未压缩，所以模型在当前查询附近仍然有清晰的局部记忆。
