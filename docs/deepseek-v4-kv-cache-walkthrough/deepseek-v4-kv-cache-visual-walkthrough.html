1. The query

The newest token creates a query vector. It is asking: which old tokens matter right now?

2. The memory

Every old token left behind cached information, so the query does not recompute the whole past.

3. The DeepSeek change

DeepSeek V4 makes each old token leave behind less memory, then summarizes older memory into larger blocks.

Why this matters

Benefits over a traditional KV cache

Less memory per old token

Traditional cache stores both K and V. DeepSeek V4 stores one shared state first, so every old token starts cheaper.

Older history gets smaller

C4A and C128A turn many shared states into fewer summary blocks, so long contexts do not grow as quickly.

Recent details stay exact

The newest tokens remain uncompressed, so the model still has sharp local memory near the current query.
