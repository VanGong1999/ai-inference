FlashAttention-3

注意力 kernel 内部更少的等待。

FlashAttention-3 保持完全相同的注意力思想，但为 Hopper GPU 重写了调度： 用 WGMMA 做更快的矩阵乘法，用 TMA 做异步的分块移动，让 softmax 与矩阵乘法重叠， 并谨慎地使用 FP8 而不让离群值主导误差。

FA2创建更多独立的 GPU 工作。

第一性原理

Horace 的有用视角：计算、内存、开销。

一台 GPU 可能被不同的事情所限制。如果数据移动是瓶颈，增加更多 FLOPs 也无济于事。如果矩阵乘法是瓶颈，你就需要张量核心。如果小运算或调度 留下了空隙，GPU 就没有真正跑在峰值上。

FA1 攻击内存流量。FA2 攻击工作划分。FA3 攻击 kernel 内部剩下的空隙， 尤其是在矩阵乘法极快的 Hopper 上。

最大的转变是，内存移动变得更像一条后台补给线，而不是 那些计算 worker 必须一步步盯着的工作。

WGMMA

WGMMA 指的是 Warpgroup Matrix Multiply-Accumulate（warp 组矩阵乘加）。不是一个 warp 发出一个更小的张量核心 运算，而是一组 warp 协作执行一条更大的矩阵乘法指令。

以前：更小的 warp 级 MMA 指令。
Hopper：warp 组发出更大的异步 WGMMA 工作。
FA3 收益：如果调度喂得好，张量核心吞吐更高。

TMA

张量内存加速器（Tensor Memory Accelerator）是 Hopper 的拷贝引擎。给它一个分块形状和内存布局， 它就能把分块移进共享内存，而且每个线程的地址运算更少。

以前：许多线程计算地址并发出拷贝。

绕过寄存器：数据走 HBM → 共享内存，而不是 HBM → 寄存器 → 共享内存。
为什么重要：临时拷贝数据占用的寄存器更少，寄存器压力下降。
另外：CUDA 核心对矩形分块做的地址算术更少。
FA3 收益：在下一个分块到达时，计算可以继续进行。

FP8

FP8 用 8 位而不是 16 位存储数字。Hopper 张量核心可以更快地运行 FP8 矩阵乘法， 但注意力必须小心地管理缩放和离群值。

好处：更少的数据和更快的 FP8 张量核心矩阵乘法。
风险：离群值维度会扭曲量化尺度。
FA3 的修复：混合 Q/K，让离群值能量在量化前被分散开。
异步

FA3 的主要思想：把一种工作藏在另一种工作后面。

如果矩阵乘法、内存拷贝和 softmax 各自分块进行，一些硬件单元就会闲置。 FA3 把它们流水线化：TMA 加载未来的分块，同时 WGMMA 计算当前分块，softmax 则在另一次矩阵乘法已经进行时运行。

低精度

FP8 很快，但离群值让它变得脆弱。

FP8 带来高得多的张量核心吞吐，但激活中可能包含罕见的大数值。 如果某个特征维度有一个巨大的离群值，量化就必须覆盖那个巨大的范围， 于是许多正常值就变得粗糙。

FA3 使用非相干处理（incoherent processing）：在 FP8 量化之前，对 Q 和 K 应用随机符号的 Hadamard 变换来分散离群值能量。

最终对比

FA2 把更多工作交给 GPU。FA3 移除了那些工作内部的等待。

这个故事是累积的。FA3 并没有取代 FA1/FA2 的洞见。它在它们之上构建， 让注意力 kernel 更紧密地匹配 Hopper 的硬件。

FA1

避免在 HBM 中物化 N × N 注意力矩阵。使用分块和在线 softmax。

FA2

改进工作划分和并行度，让更多线程块和 warp 保持有用。

FA3

利用 Hopper：WGMMA、TMA、重叠的矩阵乘法/softmax，以及带离群值感知混合的 FP8。

FA3 心智模型：最好的 kernel 不只是快工作。它是快工作，而且工作之间更少空档。
